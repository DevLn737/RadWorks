# Security Policy

Please do **not** disclose security issues publicly first.

## Reporting a vulnerability
- Contact the maintainers privately (preferred channel: direct private contact from repository owners).
- Include:
  - affected version/commit,
  - clear reproduction steps,
  - impact assessment,
  - suggested mitigation if known.

## Disclosure
- We will acknowledge receipt and coordinate a fix.
- Public disclosure should happen only after a patched release is available or maintainers confirm timing.
